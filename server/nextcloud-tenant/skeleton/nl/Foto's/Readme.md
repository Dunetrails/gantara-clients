# Foto's

Een plek voor je foto's.

- **Back-up van je telefoon**: installeer de app Nextcloud Files ([zo werkt het](https://gantara.eu/nl/help/phone-apps)), zet **Automatisch uploaden** aan in de instellingen en kies deze map.
- **Kom je van Google Foto's of Apple Foto's?** Lees [Google Foto's](https://gantara.eu/nl/help/move-from-google-photos) of [Apple Foto's](https://gantara.eu/nl/help/move-from-apple-photos).
