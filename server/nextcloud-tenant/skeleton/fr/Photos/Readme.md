# Photos

Un endroit pour vos photos.

- **Sauvegarder votre téléphone** : installez l’application Nextcloud Files ([comment faire](https://gantara.eu/fr/help/phone-apps)), activez l’**envoi automatique** dans ses paramètres et choisissez ce dossier.
- **Vous venez de Google Photos ou d’Apple Photos ?** Lisez [Google Photos](https://gantara.eu/fr/help/move-from-google-photos) ou [Apple Photos](https://gantara.eu/fr/help/move-from-apple-photos).
