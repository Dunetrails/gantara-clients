# Bienvenue sur Gantara

Voici votre propre espace de stockage, en Europe. Pour bien démarrer, nous y avons placé quelques fichiers d’exemple.

- **Envoyer des fichiers** : faites glisser des fichiers dans cette fenêtre, ou utilisez le bouton **+ Nouveau**.
- **Modifier dans votre navigateur** : dans *Documents*, ouvrez le document, le tableur ou la présentation d’exemple.
- **Partager** : cliquez sur l’icône de partage à côté d’un fichier ou d’un dossier pour créer un lien.
- **Formule Family ou Team ?** Les dossiers que d’autres partagent avec vous apparaissent aussi ici.
- **Sur tous vos appareils** : installez l’[application de bureau](https://gantara.eu/fr/help/desktop-app) et l’[application pour téléphone](https://gantara.eu/fr/help/phone-apps).
- **Vous venez d’un autre service ?** Lisez [Quitter Google Drive, Dropbox ou iCloud](https://gantara.eu/fr/help/moving-to-gantara).

Des questions ? Consultez le [centre d’aide](https://gantara.eu/fr/help).
