# Photos

A place for your photos.

- **Back up your phone**: install the Nextcloud Files app ([how](https://gantara.eu/help/phone-apps)), turn on **Auto upload** in its settings and choose this folder.
- **Coming from Google Photos or Apple Photos?** See [Google Photos](https://gantara.eu/help/move-from-google-photos) or [Apple Photos](https://gantara.eu/help/move-from-apple-photos).
