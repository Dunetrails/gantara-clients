# Welcome to Gantara

This is your own storage, in Europe. To help you get started, we put a few example files here.

- **Upload**: drag files into this window, or use the **+ New** button.
- **Edit in your browser**: in *Documents*, open the example document, spreadsheet or presentation.
- **Share**: click the share icon next to a file or folder to create a link.
- **On a Family or Team plan?** Folders that others share with you appear here too.
- **On all your devices**: install the [desktop app](https://gantara.eu/help/desktop-app) and the [phone app](https://gantara.eu/help/phone-apps).
- **Coming from another service?** See [Moving from Google Drive, Dropbox or iCloud](https://gantara.eu/help/moving-to-gantara).

Questions? Visit the [help centre](https://gantara.eu/help).
